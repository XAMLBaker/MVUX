Commands

把方法
暴露为命令

`public` 方法会被生成器转换成 `ICommand`，并套用参数与 `CancellationToken` 规则。

文档首页State
条件`public` 方法
返回`void` / `Task` / `ValueTask`
扩展feed parameter / command parameter

示例

public async ValueTask AddFavorite(CancellationToken ct)
{
    var city = await City;
    if (city != null)
        await Favorites.AddAsync(city, ct);
}

要点

  • 命令直接从模型方法生成。
  • 状态更新和选择更新都可以写进命令体。
