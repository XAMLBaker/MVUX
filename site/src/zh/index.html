核心概念

数据使用 IFeed，状态使用 IState，列表使用 IListFeed / IListState。Option<T> 和 Message<T> 则把值轴与加载轴分开。

Selection

ListFeed.Value(...).WhenSelected(...) 用于把选择状态明确地连接到列表。XAML 的 SelectedItem 绑定可以省掉。

API

类型含义
Option<T>Undefined / None / Some 状态轴
Message<T>独立的 Data / IsLoading / Error 轴
IFeed<T>只读响应式数据流
IState<T>可读可写的单值状态
ListFeed.Value静态列表 feed
ListFeed.Async异步列表 feed
ListState.Value可编辑列表状态
Selection同步列表选择状态
WhenSelected把选择连接到 ListFeed/ListState
FeedView在 XAML 中渲染 feed 状态
Commands把模型方法暴露成命令
