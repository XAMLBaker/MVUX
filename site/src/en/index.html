Core concepts

Data is split into IFeed, state into IState, and lists into IListFeed / IListState. Option<T> and Message<T> separate value and loading axes.

Selection

ListFeed.Value(...).WhenSelected(...) connects selection state to a list explicitly. XAML SelectedItem binding disappears.

Samples

WPF and Avalonia samples demonstrate the same concept on both platforms.

UI rendering

FeedView subscribes to IFeed<T> and renders Loading / Data / Error / None within one control.

API

TypeMeaning
Option<T>Undefined / None / Some state axis
Message<T>Independent Data / IsLoading / Error axes
IFeed<T>Read-only reactive data stream
IState<T>Readable/writable single state
ListFeed.ValueStatic list feed
ListFeed.AsyncAsync list feed
ListState.ValueEditable list state
SelectionSync list selection state
WhenSelectedConnect selection to ListFeed/ListState
FeedViewRender feed state in XAML
CommandsExpose model methods as commands
