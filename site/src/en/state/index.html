State

A single value
with read/write flow

`IState` is a reactive state that you can await and update with `SetAsync` or `UpdateAsync`.

Docs homeListState
Primary`State.Value`
Async`State.Async`
Writes`SetAsync` / `UpdateAsync`

Example

public IState<string> City => State.Value(this, () => "Seoul");
public IState<string> SelectedCity => State<string>.Empty(this);

Notes

  • `IState` represents a single value.
  • Selection is state too, so it belongs here.
