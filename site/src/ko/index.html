MVUX 패턴을
WPF와 Avalonia에서

Luke.Mvux는 Uno Platform MVUX의 API 감각을 WPF와 Avalonia에서 독립적으로 재구현한 라이브러리입니다. 핵심은 Feed, State, Message, Option, FeedView, Selection, Commands를 분리해서 UI 상태 흐름을 명시적으로 만드는 것입니다.

빠른 시작

플랫폼 패키지를 설치하면 컨트롤과 소스 제너레이터가 함께 들어옵니다.

dotnet add package Luke.Mvux.Wpf
dotnet add package Luke.Mvux.Avalonia

Selection 동기화는 앱 시작 시점에 한 번 등록합니다.

// WPF
protected override void OnStartup(StartupEventArgs e)
{
    this.UseMvux();
    base.OnStartup(e);
}

// Avalonia
AppBuilder.Configure<App>()
    .UseMvux()
    .UsePlatformDetect();

1. State

IState<T>는 현재 값을 가지는 상태입니다. 사용자가 입력하거나 선택한 값처럼 쓰기 가능한 값에 씁니다.

2. Feed

IFeed<T>는 읽기 전용 데이터 흐름입니다. API 조회, 계산 결과, 다른 상태에서 파생된 값에 씁니다.

3. View

FeedView와 generator가 feed/state를 WPF/Avalonia 바인딩 형태로 연결합니다.

FeedView 문서

핵심 모델 예시

public partial record WeatherModel(IWeatherService WeatherService)
{
    public IState<string> City => State.Value(this, () => "Seoul");

    public IFeed<WeatherInfo> CurrentWeather =>
        City.SelectAsync((city, ct) => WeatherService.GetWeatherAsync(city, ct));

    public IListState<string> Favorites =>
        ListState.Value(this, () => new List<string>());

    public IState<string> SelectedFavorite => State<string>.Empty(this);

    public IListFeed<string> FavoritesWithSelection =>
        Favorites.Selection(SelectedFavorite);

    public async ValueTask AddFavorite(CancellationToken ct)
    {
        var city = await City;
        if (city != null)
            await Favorites.AddAsync(city, ct);
    }
}

API 한눈에 보기

API역할주로 쓰는 곳
Option<T>Undefined / None / Some 3단계 값데이터 존재 여부 표현
Message<T>Data / IsLoading / Error 독립 축로딩 중 기존 데이터 유지
IFeed<T>읽기 전용 반응형 데이터 스트림API 조회, 파생 데이터
IState<T>읽기/쓰기 가능한 단일 상태입력값, 선택값, 현재 값
IListFeed<T>읽기 전용 리스트 feed조회 목록, 계산된 목록
IListState<T>수정 가능한 리스트 상태즐겨찾기, 큐, 편집 목록
FeedViewLoading / Data / Error / None 렌더링XAML 상태 화면
Selection리스트와 선택 상태 연결SelectedItem 바인딩 제거
WhenSelectedSelection의 MVVM 친화 편의 API읽기 쉬운 선택 연결 예제
Commands모델 메서드를 ICommand로 생성버튼, 메뉴, CommandParameter

Feed 연산자

  • Select와 SelectAsync로 값을 변환합니다.
  • Where로 메시지 데이터 조건을 걸 수 있습니다.
  • ForEachAsync로 직접 구독 루프를 만들 수 있습니다.

List 연산자

  • ListFeed.Value는 고정 목록에 씁니다.
  • ListFeed.Async는 비동기 조회 목록에 씁니다.
  • Selection은 선택 상태를 연결하는 기본 API입니다.
  • WhenSelected는 같은 동작의 편의 API입니다.

State 연산자

  • SetAsync로 값을 바꿉니다.
  • UpdateAsync로 현재 값을 기반으로 갱신합니다.
  • SetNoneAsync로 명시적인 없음 상태를 만듭니다.
