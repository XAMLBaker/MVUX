현재 값을 가지는
쓰기 가능한 feed

IState<T>는 읽기와 쓰기가 모두 가능한 반응형 상태입니다. 텍스트 입력값, 현재 선택값, 사용자가 바꿀 수 있는 설정값처럼 “현재 값 하나”를 표현할 때 씁니다.

상황예추천 타입
사용자가 직접 바꾸는 단일 값검색어, 도시명, 토글 상태IState<T>
선택된 항목 하나선택된 도시, 선택된 카드IState<T>
읽기 전용 조회 결과서버에서 가져온 날씨IFeed<T>

기본 작성법

새 예제에서는 owner 패턴을 우선 사용합니다. 같은 프로퍼티에 여러 번 접근해도 같은 state 인스턴스가 유지됩니다.

public partial record WeatherModel(IWeatherService WeatherService)
{
    public IState<string> City => State.Value(this, () => "Seoul");

    public IState<string> SelectedFavorite => State<string>.Empty(this);
}

읽기

var city = await City;

IState<T>는 await로 현재 값을 읽을 수 있습니다. 값이 None이면 기본값이 반환됩니다.

쓰기

await City.SetAsync("Busan", ct);

SetAsync는 새 값을 넣고, 구독 중인 feed/view에 변경을 전달합니다.

비우기

await SelectedFavorite.SetNoneAsync(ct);

null을 넣는 것보다 “명시적으로 없음”을 표현할 때 의미가 분명합니다.

Feed와 조합하기

State가 바뀌면 그 State를 기반으로 만든 feed도 다시 실행될 수 있습니다.

public IFeed<WeatherInfo> CurrentWeather =>
    City.SelectAsync((city, ct) => WeatherService.GetWeatherAsync(city, ct));

Generator가 ViewModel에 노출하는 방식

모델의 IState<T>는 ViewModel에서 일반적인 바인딩 프로퍼티처럼 보입니다.

// Model
public IState<string> City => State.Value(this, () => "Seoul");

// generated ViewModel 개념
public string? City { get; set; }
