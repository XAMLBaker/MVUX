Selection

SelectedItem 바인딩 없이
선택 상태 동기화

MVUX에서 선택은 UI 이벤트가 아니라 모델의 상태입니다. 리스트와 선택 상태를 명시적으로 연결하면 XAML에는 SelectedItem 바인딩을 쓰지 않아도 됩니다.

ListState 예제WhenSelected 보기
단일 선택IState<T>
다중 선택IState<ImmutableList<T>>
XAMLItemsSource만 바인딩

단일 선택

public IListState<string> Favorites =>
    ListState.Value(this, () => new List<string> { "Seoul", "Busan" });

public IState<string> SelectedFavorite => State<string>.Empty(this);

public IListFeed<string> FavoritesWithSelection =>
    Favorites.Selection(SelectedFavorite);

Favorites는 목록 상태이고, SelectedFavorite는 현재 선택값입니다. Selection은 두 상태를 UI 선택과 동기화하는 리스트 feed를 만듭니다.

XAML

선택 상태를 XAML에서 직접 바인딩하지 않습니다. 리스트만 바인딩합니다.

<ListBox ItemsSource="{Binding FavoritesWithSelection}" />

Selection

선택 동기화의 기본 API입니다. Selection 문서의 예제는 이 이름을 기준으로 설명합니다.

Favorites.Selection(SelectedFavorite)

SelectedItem 없음

선택 상태는 모델의 IState<T>에 있고, XAML은 ItemsSource만 바인딩합니다.

<ListBox ItemsSource="{Binding FavoritesWithSelection}" />

자동 정리

선택된 항목이 리스트에서 사라지면 stale selection을 정리합니다.

다중 선택

public IState<ImmutableList<WorkCard>> SelectedCards =>
    State.Value(this, () => ImmutableList<WorkCard>.Empty);

public IListFeed<WorkCard> QueueWithSelection =>
    Queue.Selection(SelectedCards);

다중 선택 상태는 ImmutableList<T>로 표현합니다. UI에서 여러 항목을 선택하면 이 상태가 갱신됩니다.

플랫폼 초기화

Selection 동기화는 플랫폼 패키지의 초기화가 필요합니다. 앱 시작 시 UseMvux()를 한 번 호출하세요.

// WPF
this.UseMvux();

// Avalonia
AppBuilder.Configure<App>().UseMvux();
