ListState

수정 가능한
리스트 상태

IListState<T>는 IListFeed<T>이면서 동시에 Add, Remove, Update, Clear 같은 쓰기 작업을 제공합니다. 사용자가 편집하는 목록이나 앱 내부에서 관리하는 큐에 적합합니다.

Selection 연결ListFeed와 비교
읽기IListFeed<T>
쓰기Add / Remove / Update
바인딩ObservableCollection 노출

기본 작성법

public IListState<string> Favorites =>
    ListState.Value(this, () => new List<string> { "Seoul" });

새 예제에서는 owner 패턴을 권장합니다. 모델 프로퍼티에 여러 번 접근해도 같은 리스트 상태가 유지됩니다.

주요 작업

await Favorites.AddAsync("Busan", ct);
await Favorites.RemoveAsync("Seoul", ct);
await Favorites.SetAsync(["Seoul", "Incheon"], ct);
await Favorites.ClearAsync(ct);

단일 항목 업데이트

await Cards.UpdateAsync(
    card => card.Id == id,
    card => card with { Done = true },
    ct);

여러 항목 업데이트

await Cards.UpdateAllAsync(
    card => card.Owner == "Mina",
    card => card with { Escalated = true },
    ct);

선택 상태 연결

public IState<string> SelectedFavorite => State<string>.Empty(this);

public IListFeed<string> FavoritesWithSelection =>
    Favorites.Selection(SelectedFavorite);

ViewModel 노출 방식

Generator는 IListState<T>와 IListFeed<T>를 ViewModel에서 ObservableCollection<T>로 노출합니다. 그래서 XAML에서는 일반 ItemsSource처럼 바인딩합니다.

<ListBox ItemsSource="{Binding FavoritesWithSelection}" />

ListFeed와의 선택 기준

원하는 것선택
읽기만 하는 목록ListFeed
사용자가 추가/삭제/수정하는 목록ListState
선택 상태까지 연결된 목록ListFeed/ListState + Selection
