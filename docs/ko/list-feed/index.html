ListFeed

읽기 전용
리스트 흐름

IListFeed<T>는 리스트 단위로 값을 내보내는 읽기 전용 feed입니다. 서버에서 가져온 목록, 계산된 목록, 정적 목록처럼 사용자가 직접 수정하지 않는 리스트에 적합합니다.

ListState와 비교Selection 보기
정적 목록ListFeed.Value
비동기 목록ListFeed.Async
스트림 목록ListFeed.AsyncEnumerable

ListFeed를 쓰는 상황

상황예추천 API
이미 있는 고정 목록도시 목록, 필터 옵션ListFeed.Value
한 번 비동기로 가져오는 목록서버 검색 결과ListFeed.Async
계속 들어오는 목록 스트림실시간 큐, 폴링 결과ListFeed.AsyncEnumerable

정적 목록

public IListFeed<string> Cities =>
    ListFeed.Value(["Seoul", "Busan", "Incheon"]);

단순 옵션 목록처럼 로딩 상태가 필요 없는 경우에는 Async보다 Value가 더 읽기 쉽습니다.

비동기 목록

public IListFeed<WeatherInfo> Weathers =>
    ListFeed.Async(ct => WeatherService.GetWeatherListAsync(ct));

서버나 파일에서 비동기로 가져오는 읽기 전용 목록이면 ListFeed.Async가 맞습니다.

아이템 변환

Cities.Select(city => city.ToUpperInvariant())

IListFeed<T>의 Select는 리스트 자체가 아니라 리스트 안의 각 아이템에 적용됩니다.

아이템 필터

Cities.Where(city => city.StartsWith("S"))

Where도 아이템 단위 필터이며 반환 타입은 계속 IListFeed<T>입니다.

선택 연결

Cities.Selection(SelectedCity)

읽기 전용 목록에도 선택 상태를 연결할 수 있습니다.

ListFeed와 ListState 차이

목록을 직접 추가/삭제/수정해야 한다면 ListState를 사용합니다. 단순히 보여주기만 한다면 ListFeed가 더 적합합니다.
