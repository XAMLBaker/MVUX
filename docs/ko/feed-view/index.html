FeedView

Feed 상태를
템플릿으로 렌더링

FeedView는 IFeed<T>를 직접 구독하고 Loading, Data, Error, None 상태에 맞는 템플릿을 보여주는 플랫폼 컨트롤입니다.

State 보기Commands 보기
SourceIFeed<T>
템플릿Loading / Data / Error / None
새로고침RefreshCommand

모델

public IState<string> City => State.Value(this, () => "Seoul");

public IFeed<WeatherInfo> CurrentWeather =>
    City.SelectAsync((city, ct) => WeatherService.GetWeatherAsync(city, ct));

CurrentWeather는 City가 바뀔 때 다시 실행되는 읽기 전용 feed입니다.

XAML

<lib:FeedView x:Name="WeatherFeed"
              Source="{Binding CurrentWeather}">
    <lib:FeedView.LoadingTemplate>
        <DataTemplate>Loading...</DataTemplate>
    </lib:FeedView.LoadingTemplate>

    <lib:FeedView.FeedDataTemplate>
        <DataTemplate>
            <TextBlock Text="{Binding Data.City}" />
        </DataTemplate>
    </lib:FeedView.FeedDataTemplate>

    <lib:FeedView.ErrorTemplate>
        <DataTemplate>
            <TextBlock Text="{Binding Error.Message}" />
        </DataTemplate>
    </lib:FeedView.ErrorTemplate>
</lib:FeedView>

템플릿 DataContext

바인딩의미
Data현재 feed 데이터입니다.
Error현재 오류입니다.
Progress로딩 중 여부입니다. 데이터가 있으면서 로딩 중일 수도 있습니다.
Refresh템플릿 안에서 사용할 수 있는 새로고침 커맨드입니다.
Parent상위 DataContext, 보통 ViewModel입니다.

우선순위

데이터가 있으면 FeedDataTemplate이 먼저 선택됩니다. 그래서 기존 데이터를 유지한 채 Progress로 새로고침 표시를 할 수 있습니다.

RefreshCommand

<Button Content="Refresh"
        Command="{Binding RefreshCommand, ElementName=WeatherFeed}" />

리스트는 ItemsSource

IListFeed<T>와 IListState<T>는 ViewModel에서 컬렉션으로 노출되므로 일반 ItemsSource에 바인딩합니다.
