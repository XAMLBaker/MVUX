Commands

모델 메서드를
커맨드로 노출

Model의 public 메서드는 generator가 ViewModel의 IAsyncCommand로 생성합니다. 버튼 클릭, 메뉴 실행, 선택 항목 이동 같은 UI 액션을 모델 메서드로 작성할 수 있습니다.

FeedView 보기Selection 보기
대상public method
반환void / Task / ValueTask
바인딩 이름메서드 이름 그대로

기본 커맨드

public partial record WeatherModel(IWeatherService WeatherService)
{
    public IState<string> City => State.Value(this, () => "Seoul");

    public IListState<string> Favorites =>
        ListState.Value(this, () => new List<string> { "Seoul" });

    public async ValueTask AddFavorite(CancellationToken ct)
    {
        var city = await City;
        if (city != null)
            await Favorites.AddAsync(city, ct);
    }
}

AddFavorite 메서드는 ViewModel에서 같은 이름의 커맨드로 노출됩니다.

<Button Content="Add Favorite"
        Command="{Binding AddFavorite}" />

생성 규칙

규칙설명
접근 제한자public 메서드만 기본 생성 대상입니다.
반환 타입void, Task, ValueTask를 지원합니다.
취소 토큰CancellationToken은 마지막 파라미터로 둘 수 있습니다.
View 파라미터feed로 해석되지 않는 파라미터는 하나만 허용되며 CommandParameter에서 옵니다.
Feed 파라미터이름과 타입이 feed/state 프로퍼티와 맞으면 현재 값을 읽어 주입합니다.

CommandParameter

public async ValueTask AddFavoriteFromParameter(
    string city,
    CancellationToken ct)
{
    if (!string.IsNullOrWhiteSpace(city))
        await Favorites.AddAsync(city, ct);
}
<Button Command="{Binding AddFavoriteFromParameter}"
        CommandParameter="{Binding Text, ElementName=CityInput}" />

Feed 파라미터

public ValueTask UseCityFeedValue(string city)
{
    // city는 City state의 현재 값입니다.
    return ValueTask.CompletedTask;
}

파라미터 이름 city와 프로퍼티 City의 값 타입이 맞으면 암시적으로 연결됩니다.

명시적 FeedParameter

public ValueTask UseSelected(
    [FeedParameter(nameof(SelectedFavorite))] string city)
{
    return ValueTask.CompletedTask;
}

이름이 다르거나 더 분명히 표현하고 싶을 때 사용합니다.

생성 제어

[ImplicitCommands(false)]
public partial record WeatherModel(IWeatherService WeatherService)
{
    [Command]
    public ValueTask Save(CancellationToken ct) => ValueTask.CompletedTask;

    [Command(false)]
    public ValueTask Helper(CancellationToken ct) => ValueTask.CompletedTask;
}

기본은 암시적 생성입니다. 필요하면 타입이나 어셈블리 단위로 끄고, 메서드별로 다시 켤 수 있습니다.

진단

지원하지 않는 반환 타입, 두 개 이상의 view 파라미터, 잘못된 FeedParameter 매핑은 generator 진단으로 표시됩니다. 커맨드가 생성되지 않으면 먼저 메서드 시그니처를 확인하세요.
