在 WPF 和 Avalonia 中
使用 MVUX 模式

Luke.Mvux 是对 Uno Platform MVUX API 风格的独立重实现，目标平台是 WPF 与 Avalonia。 核心思路是把 Feed、State、Message、Option、FeedView、Selection、Commands 分离，让 UI 状态流更明确。

快速开始 查看 Selection 查看 FeedView
支持平台WPF, Avalonia
包Luke.Mvux.Wpf, Luke.Mvux.Avalonia
编写方式partial record Model + generator
目标XAML 保持简单，状态流保持显式

快速开始

安装平台包后，控件与源生成器会一起提供。

dotnet add package Luke.Mvux.Wpf
dotnet add package Luke.Mvux.Avalonia

Selection 同步只需在应用启动时注册一次。

// WPF
protected override void OnStartup(StartupEventArgs e)
{
    this.UseMvux();
    base.OnStartup(e);
}

// Avalonia
AppBuilder.Configure<App>()
    .UseMvux()
    .UsePlatformDetect();

核心模型示例

public partial record WeatherModel(IWeatherService WeatherService)
{
    public IState<string> City => State.Value(this, () => "Seoul");

    public IFeed<WeatherInfo> CurrentWeather =>
        City.SelectAsync((city, ct) => WeatherService.GetWeatherAsync(city, ct));

    public IListState<string> Favorites =>
        ListState.Value(this, () => new List<string>());

    public IState<string> SelectedFavorite => State<string>.Empty(this);

    public IListFeed<string> FavoritesWithSelection =>
        Favorites.Selection(SelectedFavorite);

    public async ValueTask AddFavorite(CancellationToken ct)
    {
        var city = await City;
        if (city != null)
            await Favorites.AddAsync(city, ct);
    }
}

API 一览

API作用常用场景
Option<T>Undefined / None / Some 三段值表达数据是否存在
Message<T>Data / IsLoading / Error 独立轴加载时保留旧数据
IFeed<T>只读响应式数据流API 查询、派生数据
IState<T>可读可写单值状态输入值、选择值、当前值
IListFeed<T>只读列表 feed查询列表、计算列表
IListState<T>可修改列表状态收藏、队列、编辑列表
FeedView渲染 Loading / Data / Error / NoneXAML 状态界面
Selection连接列表与选择状态去掉 SelectedItem 绑定
WhenSelectedSelection 的 MVVM 友好便捷 API更易读的选择示例
Commands把模型方法生成为 ICommand按钮、菜单、CommandParameter

Feed 运算符

  • 用 Select 与 SelectAsync 转换值。
  • 用 Where 添加消息数据条件。
  • 用 ForEachAsync 构建手动订阅循环。

List 运算符

  • ListFeed.Value 用于固定列表。
  • ListFeed.Async 用于异步查询列表。
  • Selection 是基础选择 API。
  • WhenSelected 是同等行为的便捷 API。

State 运算符

  • 用 SetAsync 设置值。
  • 用 UpdateAsync 基于当前值更新。
  • 用 SetNoneAsync 表达显式空状态。
