ListFeed

只读的
列表 feed

用于远程数据或计算出来的列表，不希望直接修改它们。

文档首页Selection
主要`ListFeed.Value`
异步`ListFeed.Async`
选择`WhenSelected(...)`

示例

public IListFeed<string> Cities
    => ListFeed.Value(["Seoul", "Busan", "Incheon"]);

public IListFeed<string> RemoteCities
    => ListFeed.Async(ct => service.GetCitiesAsync(ct));

要点

  • 只读列表用 `ListFeed` 更合适。
  • `WhenSelected(...)` 是 `IListFeed` 的扩展。
