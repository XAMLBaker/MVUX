FeedView

直接渲染
feed 状态

订阅 `IFeed`，并在 XAML 中在 Loading / Data / Error / None 之间切换。

文档首页State
目标`IFeed`
状态Loading / Data / Error / None
用途XAML 渲染

示例

<lib:FeedView Source="{Binding CurrentWeather}">
  <lib:FeedView.FeedDataTemplate>...</lib:FeedView.FeedDataTemplate>
</lib:FeedView>

要点

  • `FeedView` 把数据绑定变成 UI 状态。
  • XAML 中不需要分散条件分支。
