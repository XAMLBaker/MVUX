WhenSelected

按你想要的方式
阅读选择连接

WhenSelected(...) 的行为与 Selection(...) 相同。 差别只在阅读方向：保持列表链式结构，再在末尾补上选择语义。

Selection ListFeed
目标IListFeed<T>
返回IListFeed<T>
用途选择语法糖

为什么要多一个名字？

基础 API便捷 API
Favorites.Selection(SelectedFavorite)Favorites.WhenSelected(SelectedFavorite)
Queue.Selection(SelectedCards)Queue.WhenSelected(SelectedCards)

行为完全一致。WhenSelected 更适合用来表达“这个列表会和选择状态一起使用”。

单选

public IState<string> SelectedCity => State<string>.Empty(this);

public IListFeed<string> Cities =>
    ListFeed
        .Value(["Seoul", "Busan", "Incheon", "Daegu", "Jeju"])
        .WhenSelected(SelectedCity);

XAML

和 Selection 一样，XAML 只绑定列表，不需要 SelectedItem 绑定。

<ListBox ItemsSource="{Binding Cities}" />

多选

public IState<ImmutableList<WorkCard>> SelectedCards =>
    State.Value(this, () => ImmutableList<WorkCard>.Empty);

public IListFeed<WorkCard> QueueWithSelection =>
    Queue.WhenSelected(SelectedCards);

什么时候用？

当你希望 WhenSelected 比 Selection 更符合 MVVM 读法时使用。

什么时候用 Selection？

当你需要基础 API 名称、代码一致性，或者想直接强调底层行为时使用 Selection。

注意

WhenSelected 只适用于列表 feed，不是把单值 feed 转成列表的 projection API。
