State

带读写流的
单值状态

`IState` 是一种可等待、可用 `SetAsync` 或 `UpdateAsync` 更新的响应式状态。

文档首页ListState
主要`State.Value`
异步`State.Async`
写入`SetAsync` / `UpdateAsync`

示例

public IState<string> City => State.Value(this, () => "Seoul");
public IState<string> SelectedCity => State<string>.Empty(this);

要点

  • `IState` 表示一个单值。
  • 选择本身也是状态，所以放在这里。
