MVUX pattern
for WPF and Avalonia

Luke.Mvux is a standalone reimplementation of the Uno Platform MVUX API style for WPF and Avalonia. The core idea is to separate Feed, State, Message, Option, FeedView, Selection, and Commands to make UI state flow explicit.

Quick start

Install a platform package. Controls and source generator are included together.

dotnet add package Luke.Mvux.Wpf
dotnet add package Luke.Mvux.Avalonia

Register selection sync once at app startup.

// WPF
protected override void OnStartup(StartupEventArgs e)
{
    this.UseMvux();
    base.OnStartup(e);
}

// Avalonia
AppBuilder.Configure<App>()
    .UseMvux()
    .UsePlatformDetect();

Core model example

public partial record WeatherModel(IWeatherService WeatherService)
{
    public IState<string> City => State.Value(this, () => "Seoul");

    public IFeed<WeatherInfo> CurrentWeather =>
        City.SelectAsync((city, ct) => WeatherService.GetWeatherAsync(city, ct));

    public IListState<string> Favorites =>
        ListState.Value(this, () => new List<string>());

    public IState<string> SelectedFavorite => State<string>.Empty(this);

    public IListFeed<string> FavoritesWithSelection =>
        Favorites.Selection(SelectedFavorite);

    public async ValueTask AddFavorite(CancellationToken ct)
    {
        var city = await City;
        if (city != null)
            await Favorites.AddAsync(city, ct);
    }
}

API at a glance

CommandsGenerates ICommand from model methodsButtons, menus, CommandParameter

Feed operators

  • Use Select and SelectAsync to transform values.
  • Use Where for message data conditions.
  • Use ForEachAsync to build manual subscription loops.

List operators

  • ListFeed.Value is for static lists.
  • ListFeed.Async is for async-fetched lists.
  • Selection is the baseline selection API.
  • WhenSelected is the convenience API for the same behavior.

State operators

  • Use SetAsync to set a value.
  • Use UpdateAsync to update based on current value.
  • Use SetNoneAsync for explicit empty state.
