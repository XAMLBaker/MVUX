Common confusion points
for first-time readers

Luke.Mvux adds a feed/state model on top of familiar MVVM. At first, it can look like many names, but the key distinction is whether a type is read-only or writable.

Is this Uno MVUX?

No. It is an independent reimplementation for WPF and Avalonia that mirrors the API shape and usage feel of Uno Platform MVUX. It is not a copied Uno source project.

Which platforms are supported?

Based on current docs and samples, the supported targets are WPF and Avalonia. WinUI 3 and MAUI are outside the current scope.

Is it production-ready?

The primary goal is education and demos. For real apps, you should review API stability, error handling, and platform-specific edge cases yourself.

Feed vs State

IFeed<T> is a read-only data flow. IState<T> is a feed where you can also read and write the current value.

ListFeed vs ListState

Use ListFeed for lists you display, and ListState for lists you edit. If you need add/remove behavior like favorites, ListState is the right choice.

Why no ListState.Async?

Async fetched lists are handled by ListFeed.Async. If users must edit an initial list, fetch first and then manage it with ListState.Value.

Selection and WhenSelected

Selection is the base API, and WhenSelected is a convenience API for a more MVVM-friendly reading style. Both connect list feed and selection state.

What about SelectedItem binding?

The recommended direction is to avoid it. Connect in the model with Favorites.Selection(SelectedFavorite), and bind only ItemsSource in XAML.

Why is UseMvux needed?

Selection sync must connect with platform controls. Call UseMvux() once at app startup to register WPF/Avalonia selection synchronization.

Why use the owner pattern?

Passing owner like State.Value(this, () => value) allows reusing the same state instance even when the same model property is accessed multiple times.

How are command names mapped?

They are exposed with the same method name. A method like AddFavorite binds as Command="{Binding AddFavorite}".

Recommended reading order

If you are new, read in this order: State, ListFeed, ListState, Selection, WhenSelected, FeedView, Commands.
