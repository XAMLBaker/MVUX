Commands

Expose methods
as commands

`public` methods are turned into `ICommand` by the generator, with parameter and `CancellationToken` rules applied.

Docs homeState
Requirement`public` method
Returns`void` / `Task` / `ValueTask`
Featuresfeed parameter / command parameter

Example

public async ValueTask AddFavorite(CancellationToken ct)
{
    var city = await City;
    if (city != null)
        await Favorites.AddAsync(city, ct);
}

Notes

  • Commands are generated directly from model methods.
  • State changes and selection changes can be wired inside the command body.
