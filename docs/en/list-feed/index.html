ListFeed

Read-only
list feeds

For remote data or computed lists where you do not want direct mutations.

Docs homeSelection
Primary`ListFeed.Value`
Async`ListFeed.Async`
Selection`WhenSelected(...)`

Example

public IListFeed<string> Cities
    => ListFeed.Value(["Seoul", "Busan", "Incheon"]);

public IListFeed<string> RemoteCities
    => ListFeed.Async(ct => service.GetCitiesAsync(ct));

Notes

  • Use `ListFeed` when the list is read-only.
  • `WhenSelected(...)` is an extension on `IListFeed`.
