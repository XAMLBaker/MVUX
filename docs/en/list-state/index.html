ListState

Editable
list state

Use it for UI state where items can be added, removed, or updated.

Docs homeSelection
Primary`ListState.Value`
CapabilityCRUD
Selection`WhenSelected(...)`

Example

public IListState<string> Favorites
    => ListState.Value(this, () => new[] { "Seoul", "Busan" });

public IState<string> SelectedFavorite => State<string>.Empty(this);
public IListFeed<string> FavoritesWithSelection
    => Favorites.WhenSelected(SelectedFavorite);

Notes

  • `ListState` is for editable lists.
  • It still implements `IListFeed`, so `WhenSelected(...)` applies.
