Selection

Connect
selection explicitly

Selection moves out of XAML SelectedItem binding and into model state.

Docs home ListFeed WhenSelected
KeyWhenSelected(...)
TargetIListFeed<T>
GoalSelection sync

Example

public IListState<string> Favorites
    => ListState.Value(this, () => new[] { "Seoul", "Busan", "Incheon" });

public IState<string> SelectedFavorite => State<string>.Empty(this);

public IListFeed<string> FavoritesWithSelection
    => Favorites.WhenSelected(SelectedFavorite);

Notes

  • Selection is state, not data.
  • Keep list and selection separate, but connect them explicitly.
