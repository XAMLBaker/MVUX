FeedView

Render feed
states directly

Subscribes to `IFeed` and switches between Loading / Data / Error / None in XAML.

Docs homeState
Target`IFeed`
StatesLoading / Data / Error / None
UseXAML rendering

Example

<lib:FeedView Source="{Binding CurrentWeather}">
  <lib:FeedView.FeedDataTemplate>...</lib:FeedView.FeedDataTemplate>
</lib:FeedView>

Notes

  • `FeedView` turns data binding into UI state.
  • No need to spread branching logic across XAML.
